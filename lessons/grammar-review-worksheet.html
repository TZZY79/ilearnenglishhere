Task 1: Present Continuous (Now vs. Plan)
Choose: Is this action happening RIGHT NOW or is it a FUTURE PLAN?
FORMULA: Subject + am/is/are + Verb-ing
Task 2: Action vs. Stative Verbs
Can you SEE someone doing this? ACTION = YES. STATIVE = NO (mental/feeling)
Task 3: Would Rather vs. Prefer
Both mean the same — different grammar! Fix the errors.
Pattern Formula
Would Rather would rather + Base Verb (NO -ing)
Prefer prefer + V-ing + TO + V-ing
Task 4: INTENSIFIED — Will vs. Going To
Different moment = different grammar! Choose the right one.
GOING TO = Plan decided BEFORE you speak (already arranged)
WILL = Decision made WHILE you speak (spontaneous)
Task 5: INTENSIFIED — Probability & Modals (Might/Could/May)
How SURE are you? Pick the right word for the certainty level.
0% (Won't) → 50% (Might/Could/May) → 80% (Will Probably) → 100% (Will)
Task 6: That Clauses & Suggestions
Reporting news or making plans
Type Formula
That Clause (Heard/Said) Verb + that + Full Sentence
Suggestion Shall we... / Could we... / Let's...
Task 7: Comparison with AS...AS
Both things are the SAME when using AS...AS
FORMULA: Subject + verb + as + Adjective + as + noun
