# I Learn English Here

**Free interactive English lessons — beginner to intermediate (A1–B1).**
👉 **https://ilearnenglishhere.academy**

Classroom-tested lessons made by a working English teacher in Cambodia. Every lesson runs in the browser: no sign-up and no download. Open a lesson and start.

## What's inside

- **Interactive slideshows** with voting, reveal-the-answer and fill-in-the-gap activities
- **Auto-marking quizzes** that explain *why* an answer is right
- **Learning games** for practice in class or at home
- **Printable worksheets and study guides**
